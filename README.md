# Kirby Slack Bot

My first Slack bot, made with node.js and slack bolt. It can respond to commands like `/kirby-ping` and `/kirby-catfact`. More commands will be added in the future.

# commands

/kirby-ping - Check bot latency
/kirby-catfact - Get a cat fact
/kirby-joke - Get a random joke
/kirby-quote - Get a random quote
/kirby-advice - Get a random advice
/kirby-dogfact - Get a random dog fact

# Built with

node 
slack bolt
Axios
